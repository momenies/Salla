إعداد مطلوب قبل تسجيل الدخول

التطبيق يعمل، لكن مفاتيح الربط مع سلة غير مضبوطة

لماذا لا يعمل تسجيل الدخول؟

سلة تتعرّف على تطبيقك عبر مفتاحين سرّيين. ملف .env عندك لا يحتوي عليهما، فلو حوّلناك إلى سلة الآن سترفضك برسالة «The requested OAuth 2.0 Client does not exist».

الخطوات

  1. افتح بوابة الشركاء

    salla.partners ← تطبيقاتي ← اختر تطبيقك ← App Keys

  2. انسخ المفتاحين إلى ملف .env 
    SALLA_OAUTH_CLIENT_ID=ضع Client ID هنا
SALLA_OAUTH_CLIENT_SECRET=ضع Client Secret هنا
SALLA_OAUTH_CLIENT_REDIRECT_URI={{ callbackUrl }}
  3. ضع نفس رابط العودة في البوابة

    في صفحة التطبيق ← Callback URL، ضعه بالضبط:

    {{ callbackUrl }}

    لازم يطابق حرفاً بحرف، وإلا سترفضه سلة.

  4. أعد تشغيل التطبيق

    أوقفه بـ Ctrl+C ثم npm run dev، وجرّب الدخول من جديد.
